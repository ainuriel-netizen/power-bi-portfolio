# Power BI Analytics Portfolio

A collection of data analytics dashboards built with Power BI, demonstrating skills in data visualization, business intelligence, and analytical insights.

## Projects
### 1. Sports Shoes Market Analysis (2018–2026)

**Overview:** Comprehensive market analysis dashboard for the global sports footwear industry, tracking revenue, product performance, and geographic distribution across six major brands.

**Key Metrics:**

Total Revenue: 9.08M
Year-over-Year Growth: 12.3%
Units Sold: 75K
Average Transaction Value: $302.71

**Features:**

Revenue Analysis: Brand performance ranking, price vs. discount analysis, margin comparison
Product Deep Dive: Top-performing models, category performance (Lifestyle, Training, Basketball, Running, Gym)
Customer Segmentation: Sales by income level, gender distribution
Geographic Insights: Revenue by country, regional trends (UK as key market)
Payment & Distribution: Payment method preferences, sales channel analysis

**Visualizations:** Horizontal bar charts, combo charts (bars + line trends), pie charts, scatter plots, heatmaps

**Tools & Techniques:**

DAX formulas for YoY calculations and margin analysis
Multi-dimensional data modeling
Interactive slicers for drill-down analysis
Custom formatting for readability

### 2. San Francisco Bike Share Program Analysis (2013–2018)

**Overview:** Detailed operational analysis of the San Francisco bike-sharing system, examining usage patterns, station performance, and user demographics.

**Key Metrics:**

Total Trips: 2 Million
Active Stations: 493
Active Days: 1,406
Average Trip Duration: 16.8 minutes
Average User Age: 45 years

**Features:**

Temporal Analysis:
Trips by day of week, time of day, month
Peak usage patterns (morning: 37% of daily trips)
Seasonal trends across years
Geographic Deep Dive:
Station location mapping with usage intensity
Top 20 most-used routes
Identification of underutilized stations (turnover < 0.5)
User Profiling:
Customer type distribution (Subscribers vs. Customers)
Age group segmentation
Gender breakdown
Usage patterns by demographic
Comparative Analysis:
Period-over-period metrics (YoY, MoM, QoQ)
Regional performance comparison (San Francisco, Oakland, Berkeley, etc.)

**Visualizations:** Stacked area charts, interactive maps, matrix tables with cross-tabulation, bar charts with conditional formatting, line charts for trends

**Tools & Techniques:**

Complex DAX measures for period comparison calculations
Multi-level data modeling (dates, regions, user types)
Geographic visualization with Bing Maps integration
Heatmap formatting for pattern recognition
Cross-tabulation for multidimensional analysis
Technical Stack
BI Tool: Power BI Desktop
Data Modeling: Star schema with dimension and fact tables
Calculations: DAX (Data Analysis Expressions)
Visualization: Custom color schemes, interactive slicers, drill-through capabilities
